# Coworking Reservation API (Laravel)

API RESTful backend para la gestión de reservas de espacios de coworking, desarrollada en Laravel con autenticación stateless mediante **Laravel Sanctum**, control de acceso basado en roles y permisos (**Spatie Laravel-Permission**), respuestas estandarizadas mediante Traits, Eloquent Scopes/Accessors y documentación interactiva OpenAPI/Swagger.

## Requisitos previos

- PHP >= 8.2
- Composer
- MySQL / MariaDB (Laragon, XAMPP o servidor local)
